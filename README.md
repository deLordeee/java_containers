# java_containers
#  Todo App (Java + MongoDB)

A simple Todo web application built with Java and MongoDB, containerized using Docker.

---



###  Prerequisites

Make sure the following tools are installed:

- [Docker Desktop](https://www.docker.com/products/docker-desktop) (Windows/macOS)
- [Git](https://git-scm.com/)
- Java 17+ (optional, for local development/testing)

---

### 📥 Clone the Repository

```bash
git clone https://github.com/deLordeee/java_containers.git
cd your-repo
```

---

### 🐳 Build and Run with Docker

**Option A: Quick Start (Latest Optimized Version - `v4`, Alpine-based)**

```bash
docker compose up --build
```

Then open your browser:

[http://localhost:8080/todos](http://localhost:8080/todos)
